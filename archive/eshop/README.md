# Archiv vlastního e-shopu (GitHub Pages)

E-shop na **psochazky.cz/obchod.html** je archivovaný. Veřejný prodej běží na **Shoptetu** (např. `obchod.psochazky.cz`).

## Co je v archivu

- HTML stránky: `obchod*.html`
- JS: `js/shop-*.js`, `js/cms-obchod.js`
- Data: `data/obchod-*.json`
- Admin CMS obchodu: `admin/obchod/`
- Obrázky produktů: `images/obchod/`
- Notion/Make návody a backend objednávek (`cms-oauth/api/orders.ts`)

## Obnovení (kdyby bylo potřeba)

Soubory v této složce zkopírujte zpět do kořene repozitáře podle původní struktury a odstraňte redirect stránky v kořeni.
